Create a new React project using Vite.

React UI Builder & Template Library

⸻

⚙️ TECH STACK

Install and configure:

* React (Vite)
* react-router-dom
* firebase (latest SDK)

⸻

🔥 FIREBASE SETUP (IMPORTANT)

Initialize Firebase in the project:

Create:
/src/firebase.js

It must include:

* Firebase initialization
* Auth setup (Google Auth enabled placeholder)
* Firestore database setup
* Export:
    * auth
    * db
    * app

⚠️ DO NOT implement login logic yet
⚠️ DO NOT build auth UI
⚠️ ONLY initialize Firebase connection structure

⸻

🧭 FIREBASE SERVICES TO ENABLE (CONFIG ONLY)

Set up placeholders for:

* Firebase Authentication
* Firestore Database
* Firebase Hosting (structure ready, no deploy)

No usage in UI yet.

⸻

📦 INSTALL DEPENDENCIES

Ensure installed:

* react-router-dom
* firebase

Project must run successfully.

⸻

Create routes:

PRIVATE ROUTES (NO LOGIC YET)
